Lantern native UI design references

SwiftUI implementations use design references from the local downloaded libraries.
No React source or third-party runtime dependencies are embedded.
The upstream MIT notices are retained below. Planes free components were design references only; no Planes source is copied.

The current companion displays the user's supplied masked toy head through a native outline mask.
The original green procedural companion remains a missing-asset fallback. Its native eye tracking
is adapted from Componentry's eye-tracking design/geometry; the Componentry notice is retained below.
The user-provided Rick portrait from 0.1.2 is no longer included in this release.

The custom A-Train.mp3 alert clip is supplied by the user for this personal installation.
